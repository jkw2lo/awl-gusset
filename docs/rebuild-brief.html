Awl & Gusset · handover

What to carry into the next one

A parametric flat-pattern drafter for hand-sewn leather bags: set the dimensions, get the cut pieces, the stitch-hole plan, the hardware list and the order it goes together in. This is what it does, what it knows about leather, and which of that is worth rebuilding.

9,008 lines · one file · no build step 4.44M assertions · 2,232 configurations 6 constructions · 16 element types · 6 views counted 31 Aug 2026 — the tool is still moving
01 · Inventory

What it does today

Four capabilities, each of which took a different kind of work.

Model

  • Five shell constructions, six tops, six carry types
  • Sixteen element types placeable on six faces
  • Lining, turned or raw edges, seam allowance, leather thickness
  • Presets, and save/open as a .bag.json file

Drafting output

  • Every cut piece with its size and the formula that produced it
  • Stitch-hole plan: every run fitted to a whole number of holes
  • Hardware list, leather area with waste, thread and edge length
  • Ordered build sequence, written for the bench

Views and editing

  • Six orthographic views: front, both sides, back, top and bottom plans
  • Lit 3D model, depth-sorted, drag to turn
  • Click a part for its own controls; drag edges, corners and tabs to resize
  • Inside view: walls unrolled, plus a section through the fittings

Paper

  • Tiled sheets at 1:1 with alignment crosses and a printed ruler
  • Hand-arrangeable: drag a piece to another sheet, double-click to turn it
  • Vector PDF export written from scratch — pattern, and an info pack
  • Stitch-count sheet for reconciling a seam that has drifted

03 · Domain

What it knows about leather

These are facts about hand-sewn bags, not about this implementation — they will be true of whatever you build next. Nearly all of them exist because the obvious approach produced a pattern that could not be sewn; the tag says what each one cost.

Seams and stitch holes

Two pieces that meet must be pricked to the same number of holes.

Plan the seam once, give both pieces the same key, and read the count off the plan. This is the spine of the whole thing: it is why a gusset cannot creep against its panel, and it is the single decision that everything else hangs from.

the architecture

Every run is fitted to a whole number of holes — an even count on a symmetric run.

An even count puts one hole exactly on the centre mark, which is where you start pricking and work outward. The real pitch drifts a few microns off the iron; show that rather than hiding it.

a convention, not a scar

No hole may sit on a cut edge, and a fold is never pricked.

Pull every open run back by the seam allowance at each end. An edge hole tears out when it is punched by hand. The edge opposite a folded pocket's mouth is a fold, not a seam, and the hatched wrap round a ring bar is leather that is bending — no hole goes in it.

a stitch box that started inside a fold

Two rows of holes on the same line is a piece you cannot prick.

A strap's edge row running the full length while an attachment box put its own long side at the same inset — two rows a hair apart at two different pitches. Once tested for, the same shape turned up in six places.

six occurrences, found by one test

Counting ticks are indexed from the centre outward, never from an end.

Mark every tenth hole from the middle and you can hold two pieces together and see at a glance whether they are still in step — which is the thing that actually goes wrong halfway down a 600 mm seam. From an end it would depend which way each run was walked, and the two sides of a seam are built independently.

the fix for a real bench problem
Construction geometry

A tapered edge slants, so it measures longer than its width.

Draft the strip shorter along its length so the slanted stitch edge comes out the length the panel needs. Forget it and the gusset is longer than the thing it joins.

two separate bugs

One definition of how wide the bag opens.

W for a gusseted bag (less both top radii), W + D for a boxed body, half the base perimeter for a bucket. The zip, the zip panel, the mouth stiffener and the drawstring channel all have to read the same function.

a 33 mm error in a stiffener

A round base is measured off the drawing, not off a formula.

Walk the same polyline the stitching walks. Ramanujan's ellipse approximation is close enough to look right and far enough out to leave you 2 mm short after 600 mm of edge.

2 mm, which is a visible gap

A bucket body is straight-sided on purpose.

A flared tube is a cone, and a cone does not unroll into a rectangle — it unrolls into an annular sector. Either solve that properly or do not offer the flare.

a scope decision

Everything placed by eye is measured from the finished rim, never the blank edge.

Turn allowances, roll extensions and seam allowances all sit above the rim and all change independently. Pockets, elements, strap anchors and interior fittings need one datum that does not move when those do.

the roll top, which moves the rim

A bellows pleat folds back on itself, and the fold is not on the panel.

The panel is pricked to the finished face; the extra depth lives in the fold. Where the side pleat crosses the base pleat there is a square of leather folded over itself at each bottom corner — it is mitred, glued, and never pricked, so the run is three sections with the corners left out.

an 84 mm mismatch between panel and blank
Hardware and attachments

On a shaped end, measure from where the shape starts — not from the point.

Nine millimetres in from an almond tip is four millimetres of leather, and a pair of rivets set six either side of the centre line there is two holes in fresh air.

rivets drawn off the leather

A shaped end is offset, not shrunk.

Pull the stitch line in by a true parallel offset — every edge moving its own perpendicular distance. Insetting the bounding box shortens a point in proportion instead, so the row creeps toward the tip and the margin is only right along the sides.

a wandering seam allowance

A handle is not a short strap.

How it is built — single, layered, four-fold, rolled — decides the blank width, what stitching it carries, and how wide the tail lands on the bag. A rolled handle's tail is the strip squashed flat, much wider than the handle you hold. Give handles their own width, anchor height, fixing and rivet count.

confusion, borrowed from the strap

A four-fold blank is four times the finished width, so nothing on it can be pricked.

It gets the footprint outline and a "fold and glue first, then mark from the panel" note instead. Any build that changes the blank's width has to be asked before holes are placed.

a rule about the material
Drawing conventions

Seam allowance means the distance from the cut edge to the stitch line.

That is the number she sets her wing divider to, so anything that moves the cut edge has to move the stitch line with it. Crowning a long edge outward without crowning the row opens that gap by the full crown at mid-span.

the entasis feature, twice

Every label goes through one placement pass, and the cheapest ones lose.

Hole counts, fold labels, dimensions and the piece's own heading all compete for the same paper. Rank them, nudge a colliding one, and drop it if it still will not fit — a note that cannot be read is worse than no note. A label must also stay on its own tile; one that runs onto the neighbour reads as that piece's note.

13 overlaps, found by measuring

A number belongs on the leather it is counting.

Point every count and tick at the middle of the piece, not the middle of its tile — on a 20 mm strap the tile centre is above the blank entirely. A number in the waste is a number you burnish off.

32 of 171 labels in the margin

Say what is a fold, what is a seam, and what is pricked through two layers at once.

A dash-dot line on a 40 mm tab is a riddle unless it is labelled. Tint the strip that ends up folded underneath. Colour the runs you prick with both layers clamped together, and print the hole count next to every run — it is the fastest check there is at the bench.

legibility, earned back
04 · Engineering

What worked, and what to change

The domain rules above are portable. These are judgements about how the code was put together, and they are the ones actually worth revisiting.

Carry it over

Earned its keep

  • One self-contained file, no build step. Edit, test, publish. Nothing to install and nothing to go stale; it is why this got as far as it did.
  • Tests that run the shipped file. The suite pulls the engine straight out of the HTML and runs it in Node, so it exercises what actually ships rather than a copy.
  • Sweep the combinations, not just the presets. Presets only cover what the presets happen to use. Nearly every real bug lived in the combinations they miss.
  • Assert properties, not snapshots. "Mating runs agree", "no hole is off the blank", "no two rows coincide", "no two labels overlap" — each of those caught a class of bug, repeatedly, without needing to know the right answer in advance.
  • Every piece carries the formula that produced it. It makes the output arguable at the bench, which is the difference between a tool and a black box.
  • One definition per rule. Every duplicated rule became a divergence — the mouth width, the rivet layout, the tip profile. Name the function and make everything read it.

Do differently

Cost more than it gave

  • Built-in features and elements do the same job twice. The front pocket exists as both a fixed feature and an element type. Fold the built-ins into the elements list from the start; retrofitting it now would change every preset.
  • State grew ad hoc and round-tripping was never tested. One field is still silently dropped on save and reload. Define the design document first, and test the round trip as a property from day one.
  • Rendering, geometry and layout are interleaved. The draft produces drawing items, and the same pass positions them, styles them and lays out text. A clean split — geometry → drawing model → renderer — would make the PDF writer, the SVG and the 3D view three consumers of one thing instead of three near-copies.
  • The drag system was retrofitted twice. Once for elements, once for grips that change shape. Decide early that any parameter can have a handle on the drawing, and give them one descriptor from the start.
  • Presets carry whole state snapshots. They drift from the defaults, and adding a field means touching all of them. Store presets as sparse overrides.
  • Do not rely on the browser's print. A sandboxed frame cannot open the print dialog, so print silently did nothing for months. Plan on generating the PDF yourself.
05 · Restart

If you start again

In order of leverage. The first three are structural and are hard to add later; the rest can follow whenever.

Build the seam plan before anything is drawn.

A registry of named seams, each planned once to a hole count, with pieces subscribing to them. Everything else — panels, elements, straps — becomes a client of that registry. It is the one decision that made this tool correct rather than approximately correct.

Define the design document, and test its round trip first.

One schema, one sanitiser that clamps every value and drops what it does not know, and a test that asserts save → load → save is identical. Add fields through the schema, never beside it.

Separate geometry from drawing from rendering.

Geometry answers "where is this in millimetres". The drawing model says "this is a cut line, this is a fold, this is a run of 139 holes". Renderers turn that into SVG, PDF, or a 3D scene. Three consumers, one model — and the PDF writer stops being a second implementation of the pattern.

Make every element a first-class part with a piece, a footprint and a face.

No special cases for pockets. If the built-in features are just elements with better defaults, the element sweep tests them all at once and there is one code path to get right.

Write the property tests alongside the first feature, not after the tenth.

Each of the four properties listed opposite found real bugs the day it was written, in code that had been reviewed and looked fine. They are cheap, and they are the only reason this is trustworthy at 2,232 configurations.

Keep the bench vocabulary in the interface.

Pricking iron, wing divider, seam allowance, grain, skive, burnish. The tool is credible because it talks the way the work does; a control called "stitch density parameter" would not be.

06 · Open

Gaps and known faults

Carried forward honestly, so nothing here is a surprise later.

Bug

The sanitiser drops an element's side — which end of the gusset it sits on — so that choice is lost on every save and reload. The presets would need the field too.

Not built

Curved and shaped gussets. Only a straight taper today; a curved one needs a numeric solve for the strip length, since the edge is no longer a straight slant.

Not built

A flared bucket — the cone that unrolls to an annular sector rather than a rectangle.

Not built

A curved zip set into a front panel, which is the other way a belt bag gets built.

Not built

Nesting pieces on a hide outline to cut waste. The sheets pack to paper, not to leather.

Not built

Turned-edge allowance that varies piece by piece, and a way to see the 3D model open rather than closed.
